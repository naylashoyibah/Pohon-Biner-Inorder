📚 Pengertian Traversal Inorder

Traversal Inorder adalah metode penelusuran node pada pohon biner dengan urutan:

Kiri → Root → Kanan

Artinya node sebelah kiri dikunjungi terlebih dahulu, kemudian akar (root), lalu node sebelah kanan.
